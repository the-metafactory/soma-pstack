# Observability, error tracking, analytics

This roster category has no source. No investigator is spawned for it and no tool is called.

Record it as a gap in Sources Consulted, in one line, whatever the question:

> Observability, error tracking, analytics: no source in this pack. The runtime and usage record was not searchable.

Say in What We Don't Know which claims this leaves open when the target is defensive code (a catch block, a retry, a timeout, a rate limit, a feature flag) or a number whose origin is a measurement. The reader then knows to ask whoever holds the dashboards, the error tracker or the warehouse.

Do not substitute a log file, a stack trace in a transcript or a number in a commit message for this category. If one of those turns up, it belongs to the category whose source held it.
